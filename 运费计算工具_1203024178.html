从 Excel 批量粘贴

    
归属：（按当前选中的集运类型 + 拆段）

    
列顺序：供应商 → 运输方式(空运/海运/陆运) → 普货/敏货/不限 → 小件/大件/不限 → 按重量/按体积 → 计泡比 → 首重 → 首价 → 续步长 → 续价

    
粘贴只建「单段首重+续重」报价；需要多段混合计价（如 10kg 以下首续重、10–30kg 按单价、30kg 以上一口价）请在报价编辑抽屉里配置。
